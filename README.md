## 📋 Общие требования для получения зачета

Для получения зачета необходимо подготовить **4 комплекта заданий**:
1. **Предложенная статья (Sample Article):** *Chen et al. (2025). Latency reduction in IoT networks through edge AI deployment: A comparative study.*
2. **3 статьи по направлению подготовки (специальности):**
   - Каждая статья объемом **не менее 10 000 знаков без пробелов** (полный текст статьи).
   - Статьи должны быть опубликованы в авторитетных профильных научных изданиях (IEEE, ACM, ScienceDirect, Springer и др.).

### Структура комплекта заданий по каждой статье:
1. **Полный перевод** статьи на русский язык в научном стиле.
2. **Список из не менее 30 терминов и устойчивых выражений** с переводом и примерами цитирования из текста.
3. **TASK 1:** Анализ структуры статьи:
   - *Step 1:* Библиографические данные (журнал, том, выпуск, год, страницы, авторы, название).
   - *Step 2:* Жанр, целевая аудитория, цели и объект исследования.
   - *Step 3:* Ответы на вопросы a–e по содержанию статьи.
4. **TASK 2 (Аннотация):** Краткий аналитический реферат на английском языке с обязательным применением стандартизированных вводных клише.
5. **TASK 3 (Устная презентация):** Скрипт устного выступления на 5–7 минут речи со структурой *Opening*, *Body*, *Closing* и речевыми оборотами из методички.

## 🛠 Инструкции по конвертации документов (Pandoc)

Для компиляции Markdown-файлов в формат Microsoft Word (.docx) используется **Pandoc**:

```powershell
# Конвертация предложенной статьи:
pandoc ДолжиковДП_Англ1.md -o ДолжиковДП_Англ1.docx

# Конвертация статей по специальности:
```
